# Avto-e'lon: hisobingizni ulashdan oldin o'qing

> **Tahrir: 2026-11-11.**

**Nima bo'ladi.** Siz o'z Telegram hisobingizni TulporGo'ga ulaysiz. TulporGo siz tanlagan guruhlarga sizning
nomingizdan qatnov e'loningizni yuboradi. TulporGo — Telegram API orqali ishlaydigan mustaqil xizmat, Telegramning
rasmiy ilovasi emas (Telegram API shartlari, 2.2).

**Xavf.** Telegram avtomatik e'lonlar uchun hisobingizni vaqtincha cheklashi yoki bloklashi mumkin. Bu Telegram
qarori — TulporGo uni bekor qila olmaydi va buning uchun javobgar emas.

**TulporGo nima qiladi:**

- Telegram cheklovlarini (`FloodWait`, `PEER_FLOOD`) **hech qachon chetlab o'tmaydi**: cheklov kelsa, kutadi yoki
  to'xtaydi va sizga xabar beradi.
- Standart: har guruhga 30–60 daqiqada ko'pi bilan 1 e'lon, tasodifiy pauza bilan. Tezroq yuborishni tanlasangiz,
  xavf oshadi — buni alohida tasdiqlaysiz.
- Faqat siz tanlagan guruhlar bilan ishlaydi. Guruhlar ro'yxatini ko'rsatish uchun faqat guruh nomlari olinadi;
  shaxsiy yozishmalaringiz o'qilmaydi va saqlanmaydi.
- Sessiya shifrlangan holda O'zbekistondagi serverda saqlanadi. Login kodi va ikki bosqichli parolingiz saqlanmaydi.

**Siz nima qilasiz:** faqat a'zo bo'lgan va e'lon berish mumkin bo'lgan guruhlarni tanlaysiz va ularning qoidalariga
rioya qilasiz.

**To'xtatish.** «Hisobni uzish» tugmasi — TulporGo seansi yopiladi va sessiya darhol o'chiriladi. Seansni Telegram'ning
o'zida ham yopishingiz mumkin: Sozlamalar → Qurilmalar → «TulporGo (driver)».

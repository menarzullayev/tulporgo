# W3 — Mini App (React) + HTTP API (FastAPI)

Owns `apps/api/tulporgo_api/routes*` (create `routes/__init__.py` exporting `router`), `apps/miniapp/`,
`locales/api.py`. The app factory, deps and Mini App auth exist (`apps/api/tulporgo_api/main.py`, `deps.py`).

## API (all under `/api`, auth `Authorization: tma <initData>` unless noted)
- `GET /api/me` — profile (lang, phone set?, driver card, subscription/plan, referral link).
- `PATCH /api/me` — lang, is_woman.
- `GET /api/places?q=` — search (PlaceIndex; cache it on app state, rebuild on demand); `GET /api/places/{id}/children`.
- `POST /api/requests` — create (from/to place ids or text, depart_at ISO local time Asia/Tashkent, seats, note) →
  publishes `RequestCreated` (bot notifies drivers). `GET /api/requests/mine`, `POST /api/requests/{id}/cancel`.
- `GET /api/requests/{id}/offers`; `POST /api/offers/{id}/accept`; `POST /api/offers/{id}/counter {price}`.
- `GET /api/trips/mine`; `POST /api/trips/{id}/complete|cancel`; `POST /api/trips/{id}/rate {stars, comment}`.
- `GET /api/share/{token}` — **no auth**: public trip status page data (route, car, driver first name, status) —
  nothing else personal (decision 13).
- Driver: `POST /api/driver` (register), `POST /api/driver/documents` (multipart: license, techpass — upload each
  with the Bot API `sendDocument` to the private storage chat `settings.storage_chat_id` and keep only the returned
  Telegram `file_id`; files never touch the server disk), `GET /api/driver/offers`.
- Map tiles: OpenStreetMap via Leaflet (no API key); reverse geocoding is optional and off by default.

## Mini App (`apps/miniapp`, Vite + React + TypeScript)
- Telegram Mini App SDK via `window.Telegram.WebApp` (theme params → CSS variables, back button, main button,
  haptics); sends `initData` in the auth header.
- Screens: Home (order form: from/to with search + map pick, time, seats, women-only marker shown, note) → Offers
  (live refresh) → Trip (card, share, complete, rate); Profile (language, driver registration + documents, referral
  link, subscription status); Userbot login page for W2 (`/userbot/login`: consent → phone → code → 2FA password →
  done) calling W2's endpoints; Subscription page placeholder linking to W4's checkout endpoint.
- 5 languages: ship JSON dictionaries generated from `tulporgo_core.i18n` (`uv run python -m tulporgo_api.export_i18n`
  writes `apps/miniapp/src/i18n/*.json`) so texts stay in one place.
- Brand: colours #FFC72C / #111214 / #FFFFFF, fonts Unbounded (headings) + Manrope, mascot assets from
  `brand/telegram/out` / `brand/icons`. Mobile first, works in light and dark Telegram themes.
- `npm run build` outputs static files served at `settings.miniapp_url` (domain-locked methods, Bot API 10.2).
- Tests: vitest for components/utilities, API tests with FastAPI TestClient (pytest) incl. auth failures.

## Done when
Every endpoint has pytest coverage with signed initData (and negative tests: no/forged auth, someone else's request,
wrong state, public share page leaks no phone), the Mini App builds (`npm run build`) and its tests pass, full suite +
ruff green.
